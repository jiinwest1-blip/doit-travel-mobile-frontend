# Do it(또잇) — AI Travel Planner Frontend

모바일 우선의 반응형 PWA 프론트엔드입니다. AI 여행 일정 생성, 지도 기반 동선 검토, 항공권 가격 비교, 여행 기록이라는 또잇의 핵심 흐름을 인터랙티브한 화면으로 구현했습니다.

## 구현 범위

| 화면 | 내용 |
|---|---|
| 홈 | 진행 중인 도쿄 여행, 오늘의 동선, 항공권 가격 카드, 여행 기록 진입점 |
| 계획 | AI 일정 초안, 일차 선택, 지도 핀, 타임라인, 일정 저장·재계산 인터랙션 |
| 탐색 | 목적지 검색 UI, 개인화된 다음 목적지 제안, 여행 취향 문서 카드 |
| 기록 | 여행 아카이브, 장소별 추천·보통·비추천 평가, 여행 기록 진입점 |
| 마이 | 여행 취향, 다음 여행의 항공 태그, 저장·개인화 설정 진입점 |

## 기술 구성

React 19, TypeScript, Vite, Tailwind CSS 4를 기반으로 작성했습니다. 모바일 환경의 `viewport-fit`, 웹 앱 매니페스트, 서비스 워커 등록을 포함해 설치 가능한 PWA의 기본 구조를 갖췄습니다. 지도 화면은 프로젝트 템플릿의 지도 컴포넌트를 활용하며, 외부 데이터·AI·결제 기능은 이번 프론트엔드 범위에 포함되지 않습니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

프로덕션 빌드는 다음 명령으로 검증합니다.

```bash
pnpm check
pnpm build
```

## 디자인 원칙

‘항공 라운지 글래스’ 방향으로, Midnight Navy 위에 Aurora Blue를 시스템 신호색으로 사용합니다. Horizon Halo, Boarding-Line Timeline, Frosted Fare Chip을 반복되는 기능성 브랜드 문법으로 적용했습니다. 상세 규칙은 [ideas.md](./ideas.md)를 참고하세요.
